# Shelf2Support

## Description
Shelf2Support is a console-based Data Structures project developed in C.
The system helps manage product expiry dates and reduces wastage by providing
smart suggestions such as discounts and donor recommendations for near-expiry items.

## Objectives
- To track product expiry dates efficiently
- To minimize wastage of products
- To suggest discounts for near-expiry products
- To recommend suitable donors for products nearing expiry

## Technologies Used
- Language: C
- Platform: Ubuntu (WSL)
- Tools: GCC Compiler
- Version Control: Git & GitHub

## Data Structures Concepts Used
- Arrays
- Linked Lists
- Binary Search Trees
- Priority Queue
- Hashing
- Searching
- Conditional Logic

## Features
- Add and store product details
- View all stored product records
- Check expiry status of products
- Suggest discounts for near-expiry products
- Suggest donors for products nearing expiry
- Persistent storage using files
